MMD Mode Auto Setup Tool

本ツールは、VRChatアバターにおいて「MMDワールドでの表情・リップシンク連動」を正しく反映させるためのセットアップを自動化するエディタ拡張スクリプトです。🐾

■ 導入方法

unitypackageのインポート

  • Unityメニュー Assets → Import Package → Custom Package を選択して MMDModeAutoSetupTool.unitypackage をインポート。

ツールを開く

  • メニュー Tools → MMD Mode Auto Setup Tool を選択。

言語の選択

  • 右上のボタンで言語を切り替えられます。

アバターのセット

  • Hierarchy上のアバターをドロップエリアにドラッグ＆ドロップ。

セットアップ実行

  • セットアップ実行 ボタンをクリック。完了ダイアログが出れば成功です。

■ セットアップ完了後にできること

Base Layerステート追加
ParametersMMDMode追加
Ex Menuトグル追加

【VRChat内での使い方】

アクションメニューから MMDMode を ON にしてください。MMDワールドの椅子に座った際（InStationがtrue時）、自動でMMDモードが有効化されます。離席すると自動で解除されます。

■ 重要：シェイプキーの調整について

【仕様上の挙動】

FaceEmoの設定は反映されない：MMDモードONでのダンス中、FaceEmoによるシェイプキー設定は事実上無効化されます。

数値の倍加：上記を回避するためにボディ側のシェイプキーを直接設定すると、数値が倍近く反映されてしまう場合があります。

【解決策】

MMD中も正しい見た目を維持したい場合は、ボディ側のシェイプキー数値を「理想の数値の半分」に設定して調整を行ってください（例：40にするなら20に設定）。

■ 注意事項・トラブルシューティング

  • バックアップ: 実行前に必ずアバターのバックアップを取ってください。
  • 容量制限: メニューやパラメーターの空き容量（1bit/1スロット）を確認してください。

【How to use in VRChat】

Turn MMDMode ON in the Action Menu. When you sit on an MMD station (InStation=true), MMD mode activates. It automatically deactivates when you stand up.

■ Important: Shape Key Adjustment

【Behaviors】

FaceEmo settings are ignored: While dancing in MMD mode, FaceEmo shape key overrides are disabled.

Value Doubling: If you set body shape keys directly to compensate, values might appear doubled in MMD worlds.

【Solution】

Set body shape key values to "Half of your target value" (e.g., set to 20 to achieve 40 during dance).

【VRChat에서의 사용법】

■ 중요: 쉐이프키 조정에 관하여

【사양 상의 거동】

FaceEmo 설정은 반영되지 않음: MMD 모드가 켜져 있는 동안 FaceEmo의 쉐이프키 설정은 무시됩니다.

수치 배가 현상: 이를 피하기 위해 바디의 쉐이프키를 직접 설정하면, 수치가 약 2배로 반영될 수 있습니다.

【해결책】

MMD 중에도 올바른 모습을 유지하려면, 바디의 쉐이프키 수치를 "원하는 값의 절반"으로 설정하세요.

【VRChat 内的操作】

在 Action Menu 中将 MMDMode 设为 ON。坐在 MMD 舞台的椅子上时（InStation 为 true），将自動启用 MMD 模式。

■ 重要：关于 Shape Key 的调整

【行为说明】

FaceEmo 设置将失效：在 MMD 跳舞期间，FaceEmo 的 Shape Key 设置将被禁用。

数值翻倍：为了补偿而直接设置 Body 的 Shape Key 时，数值可能会翻倍显示。

【解决方案】

若想维持效果，请将 Body 的 Shape Key 数值设置为“目标数值的一半”。

■ 注意事項与故障排除

  • 备份: 请务必在运行前备份角色。
  • 容量限制: 占用 1 bit / 1 個项目。请检查容量。
