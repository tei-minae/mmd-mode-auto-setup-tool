MMD Mode Auto Setup Tool

取扱説明書 | User Manual

本ツールは、VRChatアバターにおいて「MMDワールドでの表情・リップシンク連動」を正しく反映させるためのセットアップを自動化するエディタ拡張スクリプトです。にゃ🐾

導入方法

unitypackageのインポート

  • Unityのメニュー Assets → Import Package → Custom Package を選択。
  • 配布された MMDModeAutoSetupTool.unitypackage をインポートします。全てのファイルにチェックを入れて Import してください。

ツールを開く

  • インポート完了後、Unityメニュー Tools → MMD Mode Auto Setup Tool を選択するとウィンドウが開きます。

言語の選択

  • ウィンドウ右上のボタンから English / 日本語 / 한국어 / 中文 の4言語をリアルタイムで切り替え可能です。

アバターのセット

  • Hierarchy上のアバターをツール内のドロップエリアにドラッグ＆ドロップします。
  • ※アバターには VRC Avatar Descriptor が必要です。

セットアップ実行

  • セットアップ実行 ボタンをクリック。「完了」ダイアログが表示されれば成功です！

セットアップ完了後にできること

ツールを実行すると、以下のアセットが自動的に更新・設定されます。

Base LayerMMD_Mode ステート追加
ParametersMMDMode (Bool) 追加
Ex MenuMMDMode トグル追加

【VRChat内での使い方】

アクションメニューから MMDMode を ON に設定してください。MMDワールドの椅子（Station）に座った際（InStationがtrueの時）、自動的にMMDモードが有効化され、ワールド側の表情・リップシンクが連動します。離席すると自動で解除され、通常のFXレイヤーが有効に戻ります。

■ 重要：シェイプキーの調整について

FACEemo等のデフォルト設定で「かかと上げ」などのシェイプキーを使用している場合、以下の仕様・挙動にご注意ください。

【仕様上の挙動】

FaceEmoの設定は反映されない：MMDモードONでのダンス中、FaceEmoによるシェイプキー設定は無効化されます。

数値の倍加・変化：上記を回避するためにボディ側のシェイプキーを直接設定すると、加算や乗算の影響により、数値が倍近く（過剰に）反映されてしまう場合があります。

【解決策】

MMD中も正しい見た目を維持したい場合は、ボディ側のシェイプキー数値を「理想の数値の半分」に設定して調整を行ってください。

例: 数値「40」で維持したい場合、ボディ側の数値を 「20」 に設定する。

※本挙動は環境やアバター構成に依存する可能性があるため、個別の微調整をお願いいたします。

注意事項

  • アバターについて: Hierarchy配置アバターが対象です。Project内のPrefabには対応していません。必ず事前にバックアップを取ってください。
  • Baseレイヤー: コントローラー未設定の場合、SDK標準品をコピーして MMDModeSetupTool/Generated/ フォルダに自動生成します。
  • リソース制限: ExpressionParametersは 1bit、ExpressionMenuは 1スロット 消費します。上限に達している場合はセットアップされません。
  • 動作仕様: Write Defaults 設定に関わらず、FXレイヤー自体を無効化して連動を実現します。そのためMMD着席中は着替え等のFX機能は使用不可となります。

トラブルシューティング

現象確認・対策
セットアップが完了しない Unityの Console ウィンドウに赤いエラーが出ていないか確認してください。
「SDKのデフォルトBaseコントローラーが見つかりません」 VRChat SDKを公式から再インポートしてから再度実行してください。
メニューに項目が出ない メニューやパラメーターの空き容量（8項目/256bit）を確認してください。
メニューにMMDModeトグルが表示されない / パラメーターが反映されない ExpressionMenuのバージョンが古い等の理由で、ExpressionParametersの変更が正しく反映されないケースがあります。その場合は、ExpressionMenuを新しく作成（右クリック > Create > VRChat > Avatars > Expressions Menu）し、アバターに差し替えてから再度実行してください。
MMDで表情が動かない アバターの構成（特殊なAnimator構成等）により、追加の個別調整が必要な場合があります。
