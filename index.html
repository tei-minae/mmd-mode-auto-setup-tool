MMD Mode Auto Setup Tool

導入方法

本ツールは、VRChatアバターにおいて「MMDワールドの表情・リップシンク連動」を自動化するツールです。

1. unitypackage をインポート。
2. Tools → MMD Mode Auto Setup Tool を開く。
3. アバターをセットして セットアップ実行 をクリック。完了ダイアログが出れば成功です。

■ 重要：シェイプキーの調整について

【仕様上の挙動】

FaceEmoの設定は反映されない：MMDモードONでのダンス中、FaceEmoによるシェイプキー設定は無効化されます。

数値の倍加・変化：上記を回避するためにボディ側のシェイプキーを直接設定すると、加算や乗算の影響により、数値が倍近く反映されてしまう場合があります。

【解決策】

ボディ側のシェイプキー数値を「理想の数値の半分」に設定してください（例：40にするなら20に設定）。

※構成に依存するため、個別の微調整をお願いします。

Usage Guide

This tool automates the setup for "MMD Eye/Lip Sync" on VRChat avatars.

1. Import the unitypackage.
2. Open Tools → MMD Mode Auto Setup Tool.
3. Drag & drop your avatar, then click Install MMD Mode. Success!

■ Important: Shape Key Adjustments

【Behaviors】

FaceEmo settings are ignored: While MMD mode is active, FaceEmo overrides are disabled.

Value Doubling: Manually setting shape keys might result in doubled or excessive movement due to additive/multiplicative effects in MMD worlds.

【Solution】

Set the body's shape key values to "Half of your target value" (e.g., set to 20 to achieve 40 during dance).

*Results may vary; please fine-tune based on your avatar model.

사용 방법

이 툴은 VRChat 아바타에서 "MMD 월드의 표정 및 립싱크 연동"을 자동화합니다.

1. unitypackage를 임포트합니다.
2. Tools → MMD Mode Auto Setup Tool을 엽니다.
3. 아바타를 드래그 앤 드롭하고 세팅 실행을 클릭하세요. 성공!

■ 중요: 쉐이프키 조정에 관하여

【사양 상의 거동】

FaceEmo 설정은 반영되지 않음: MMD 모드가 켜진 상태에서 FaceEmo의 쉐이프키 설정은 무효화됩니다.

수치 배가 현상: 이를 피하기 위해 바디의 쉐이프키를 직접 설정하면, 수치가 약 2배로 과하게 반영될 수 있습니다.

【해결책】

바디의 쉐이프키 수치를 "이상적인 수치의 절반"으로 설정하세요 (예: 40으로 유지하고 싶다면 20으로 설정).

*아바타 구성에 따라 미세 조정이 필요할 수 있습니다.

使用指南

本工具可自动完成 VRChat 角色的“MMD 世界表情与口型同步”设置。

1. 导入 unitypackage。
2. 打开 Tools → MMD Mode Auto Setup Tool。
3. 拖入角色并点击 执行设置。成功！

■ 重要：关于 Shape Key 的调整

【行为说明】

FaceEmo 设置将失效：在 MMD 模式开启期间，FaceEmo 的 Shape Key 设置将被禁用。

数值翻倍/变化：若直接在 Body 上设置 Shape Key，受叠加影响，数值可能会变为原来的两倍左右。

【解决方案】

请将 Body 的 Shape Key 数值设置为“理想数值的一半”（例如：若想维持在 40，请设置为 20）。

*根据角色配置不同，请手动细调。
